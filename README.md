# mapa de território 

Aplicativo para gerenciar territórios, serviço de campo, eventos, dirigentes e formulários S-13 de uma congregação.

## 📱 Módulos

| Módulo | Descrição |
|---|---|
| **Territórios** | Cadastro, mapa, designações, grades de dirigente e quadras trabalhadas |
| **Serviço de Campo** | Programação semanal e grupos |
| **Eventos** | Assembleias, congressos, visita do superintendente |
| **Dirigente** | Escala e designações |
| **S-13** | Formulário digital de designação de território |
| **Admin** | Usuários, permissões e configurações |

## 🚀 Tecnologias

- **Flutter** (Dart)
- **Riverpod** — gerenciamento de estado
- **Drift** — banco local (offline-first)
- **Supabase** — backend e sincronização
- **Flutter Map** — mapas com OpenStreetMap
- **Codemagic** — CI/CD (build automático de APK/IPA)
